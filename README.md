### Store · Plataforma de E-commerce em Microsserviços
<sub>1º sem. 2026 · Java, Spring Boot, PostgreSQL, Docker, Kubernetes, Jenkins · <a href="https://github.com/Plataformas-Micro">github.com/Plataformas-Micro</a></sub>

- Backend em Java (Spring Boot) com seis microsserviços independentes (contas, autenticação, produtos, pedidos, câmbio e API Gateway), cada um em repositório próprio e com biblioteca de contrato (OpenFeign e DTOs) separada da implementação

- Containerização com Docker e Docker Compose, manifests Kubernetes por serviço e pipeline CI/CD em Jenkins; serviço de câmbio em Python
